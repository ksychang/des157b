Exclamation Function

This function takes a string as an argument and returns the string with an exclamation mark appended.

Named Function

            function exclamation(aString){
                return aString + "!";
            }
console.log(exclamation("here is a string"));

Function Expression

            const aVaraiable = function exclamation(aString){
                return aString + "!";
            }
console.log(aVaraiable("here is a string"));

Arrow Function

            const aVaraiable = (aString) => {
                return aString + "!";
            }
console.log(aVaraiable("here is a string"));
